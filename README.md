# Toon Shading

A modern WebGL toon shading demo built with Three.js and Vite.
  
* [Demo](https://mnmxmx.github.io/toon-shading/dst/index.html)  
* [How To Implement Toon Shading With Webgl (in Japanese)](https://wgld.org/d/webgl/w048.html)

## Requirements
* Node.js 18+
* npm

## Development Setup  
```bash
# Clone repository  
git clone <repository-url>
cd toon-shading

# Install dependencies
npm install  

# Start development server with hot reload
npm run dev

# Open http://localhost:3000 in your browser
```

## Build for Production
```bash
# Build optimized production bundle
npm run build

# Preview production build
npm run preview
```

## Tech Stack (2025)
- **Build Tool**: Vite 5.x
- **3D Library**: Three.js 170.x  
- **Styling**: Sass with modern syntax
- **JavaScript**: ES2022 modules
- **Dev Tools**: Hot reload, source maps

## Legacy Note
This project was modernized from a 2016-era Gulp-based build system to use current 2025 web development best practices while preserving the original toon shading algorithm.
